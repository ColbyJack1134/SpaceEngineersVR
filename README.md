## WIP!

Space Engineers 1 VR Plugin

Interactable cockpits and fully playable from VR. Still WIP but largely playable. More details and quickstart coming soon.

## Installation:

Extract the plugin ZIP into Pulsar’s Legacy\Local folder, enable SpaceEngineersVR.dll in your profile (Click + and then search for SpaceEnginersVR), and launch Pulsar Legacy with SteamVR running.

Flatscreen multiplayer hosts can install the optional `SpaceEngineersVR.FlatscreenCompanion.dll` plugin.
