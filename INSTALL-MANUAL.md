## Installing manually from a release

GitHub releases can be newer than the version on the Pulsar plugin hub. If you install a release manually, disable the hub copy of **Space Engineers VR** so only one is enabled.

1. Install [Pulsar](https://github.com/SpaceGT/Pulsar).
2. Download `SpaceEngineersVR-vXXXX.zip` from the [latest release](https://github.com/ColbyJack1134/SpaceEngineersVR/releases/latest).
3. Extract the ZIP into Pulsar's `Legacy\Local` folder. Launch `Legacy.exe` at least once to create this folder.
4. Launch `Legacy.exe`, go to `Plugins`, click **+** to Add Plugin, search for **SpaceEngineersVR**, and click the checkbox to enable
<img width="1243" height="636" alt="image" src="https://github.com/user-attachments/assets/c7d39a03-e121-4512-a78a-fbfd957359cf" />

5. Don't forget to click **Apply**!
6. Launch Pulsar Legacy again with SteamVR running.

**Note**: If you extract the ZIP and it fails to load via Pulsar, it may be blocked. Try: right click each DLL -> Properties -> Unblock

Flatscreen multiplayer hosts and clients can install the optional `SpaceEngineersVR.FlatscreenCompanion.dll` plugin from the same release.
